# Registration Form Validation

A simple and responsive **Registration Form** built using **HTML, CSS, and JavaScript**. This project demonstrates real-time form validation by validating user input as the user types and enabling the submit button only when all fields are valid.

## 🚀 Features

- Real-time validation using JavaScript
- Name field validation (cannot be empty)
- Email format validation using Regular Expressions (Regex)
- Password validation with a minimum length of 6 characters
- Displays user-friendly error messages
- Submit button remains disabled until all inputs are valid
- Clean and responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation & Event Listeners)

## ✅ Validation Rules

- **Name:** Required field
- **Email:** Must be in a valid email format
- **Password:** Minimum of 6 characters
